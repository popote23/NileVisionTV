NileVision TV - Android 5.0+ (minSdk 21)
1) Ouvrir le dossier dans Android Studio et laisser Gradle synchroniser.
2) Build > Build APK(s). Copier l'APK sur la box (cle USB / ADB) et installer.
Telecommande : Haut/Bas = naviguer, OK sur une chaine = lecture, OK a nouveau = plein ecran,
Haut/Bas en plein ecran = zapping, Retour = quitter le plein ecran.
Les chaines viennent des listes publiques iptv-org (modifiables dans Catalog.java).
